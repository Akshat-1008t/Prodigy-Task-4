# Personal Portfolio Website — Task 04

A responsive personal portfolio website built with HTML, CSS, and vanilla JavaScript as Task 04 of the Prodigy InfoTech Web Development Internship.

## Features

- Responsive layout for desktop, tablet, and mobile
- Sticky navigation with active section indication
- Mobile navigation menu
- Hero, About Me, Skills, Projects, and Contact sections
- Project cards for Nirikshan, Lift X Brand, and Tic-Tac-Toe
- Contact form that prepares an email using the visitor's email application
- Reduced-motion accessibility support
- No build tools or external JavaScript dependencies

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)

## Run locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.

## Customize before publishing

- Replace the `AT` placeholder in the About section with your own photo if desired.
- Update the education, skills, project descriptions, and project links to match your current work.
- In `script.js`, replace `akshat@example.com` with the email address where you want to receive messages.
- Add your GitHub and LinkedIn links to the navigation or contact section if you want them displayed.
